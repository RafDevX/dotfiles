# Host Naming Scheme

## Personal Computers: Cities in the Netherlands

See: https://en.wikipedia.org/wiki/List_of_cities_in_the_Netherlands

No specific criteria for city selection.

## Servers: Stars (Modern Proper Name)

See: https://en.wikipedia.org/wiki/List_of_proper_names_of_stars

Choose a name from the list in the order A -> Z. For example, if the last server
is named after a star starting with A, the next server should be named after a
star whose name starts with B.
